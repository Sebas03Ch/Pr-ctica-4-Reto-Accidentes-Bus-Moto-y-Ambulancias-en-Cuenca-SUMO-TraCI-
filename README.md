# 🚑 Simulación de Flotas de Emergencia y Gestión Hospitalaria en SUMO/TraCI

Repositorio oficial para el desarrollo del Taller de Simulación de Tráfico y Sistema de Emergencias Médicas (EMS) en la red urbana de Cuenca, Ecuador (Universidad de Cuenca). Este proyecto implementa la interacción microscópica entre vehículos de transporte público, motocicletas y flotas de ambulancias mediante SUMO (Simulation of Urban MObility) y la API de control en tiempo real TraCI (Python).


## Estructura del Repositorio

El repositorio está organizado en dos scripts principales correspondientes a las fases de validación del taller:

```text
├── reto_ambulancias.py   #  APARTADO A: Mapeo de red, hospitales y prueba de despacho (Fases 1, 2 y 3)
├── reto_B.py                 #  APARTADO B: Simulación integral, gestión de incidentes, despachos y Fase 5 (CSV y Gráficos)
